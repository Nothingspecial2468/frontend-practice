# GitHub Finder

A simple GitHub user search app built with vanilla JavaScript that lets users look up any GitHub profile and view their public information and repositories.

## 🚀 Features

- Search for any GitHub username
- Display profile details like avatar, bio, location, and join date
- Show followers, following, and repo counts
- View public repositories with metadata
- Open profile and repo links in a new tab
- Error handling for invalid or missing users

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- GitHub REST API

## 🧠 Behind The Scenes

This project focuses on learning how frontend apps communicate with external APIs:

- capture user input from the search field
- send requests to the GitHub API
- parse JSON responses
- update the DOM dynamically with user data
- fetch and render repository information
- handle loading and error states gracefully

## Concepts practiced

- DOM manipulation
- Event listeners
- Fetch API and async/await
- API response handling
- Dynamic UI rendering
- Conditional rendering for empty or missing data
- Working with external JSON data

## ▶️ How to Run

1. Open the project folder.
2. Open `index.html` in your browser.
3. Type a GitHub username and click Search.

## 📌 Notes

This project demonstrates how a small frontend app can interact with real-world API data while keeping the interface clean and responsive.
