# Coming Soon UI

A sleek landing-page mockup for a product launch, built with HTML, CSS, and JavaScript. It includes a countdown timer, email signup form, animated background blobs, and a success confirmation message.

## Features

- Animated gradient background
- Countdown timer for launch date
- Responsive layout for mobile and desktop
- Email form UI with loading state
- Success message after submission
- Modern glassmorphism-inspired styling

## Tech Stack

- HTML
- CSS
- JavaScript
- Font Awesome icons
- Google Fonts

## Project Goals

This project focuses on:

- creating a polished launch-page design
- manipulating DOM elements dynamically
- calculating time differences with JavaScript
- handling form submit interactions
- building responsive UI layouts

## How to Run

1. Open the folder in your browser.
2. Open `index.html` directly, or run a local live preview extension.

## Notes

The countdown is set to a future date so it keeps updating automatically until launch. The email form simulates a successful sign-up state after a short delay.
