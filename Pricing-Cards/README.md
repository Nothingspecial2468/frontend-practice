# Pricing Cards

A modern, responsive pricing cards component showcasing three subscription plans with a sleek dark theme and interactive animations.

## Features

- **Responsive Design**: Automatically adapts to different screen sizes using CSS Grid
- **Three Pricing Tiers**: Basic, Pro, and Enterprise plans with different features
- **Popular Badge**: Special "Most Popular" badge highlighting the Pro plan
- **Icon Support**: Font Awesome icons for visual representation
- **Hover Effects**: Smooth animations and transform effects on card hover
- **Feature Comparison**: Clear feature lists with checkmarks and disabled features
- **Modern Styling**: Dark theme with green gradient accent colors
- **Accessibility**: Semantic HTML structure with proper heading hierarchy

## Project Structure

```
Pricing-Cards/
├── index.html      # Main HTML markup
├── style.css       # CSS styling and animations
└── README.md       # Project documentation
```

## Getting Started

1. Open `index.html` in your web browser
2. View the three pricing plans with their features
3. Hover over cards to see interactive effects
4. Click buttons to see interactivity (currently styled only)

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Grid layout, Flexbox, Gradients, Transitions
- **Font Awesome Icons**: Professional iconography
