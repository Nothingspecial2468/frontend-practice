# Team Members Showcase

A responsive team members showcase page designed to present a group of professionals in a clean, modern layout. Each profile includes a photo, role, short biography, and social media icons.

This project focuses on visual design and layout. It is a static UI project with no JavaScript interactions.

## Preview

Open `index.html` in a browser to view the page.

## Features

- Responsive team member grid
- Six profile cards with photos, roles, and biographies
- Dark theme with purple gradient accents
- CSS hover effects on profile cards and social icons
- Call-to-action section for open positions
- Font Awesome social media icons

## Project Structure

```text
TEAM-MEMBERS-SHOWCASE/
├── index.html
├── style.css
└── README.md
```

## Getting Started

1. Clone or download the repository.
2. Open the `TEAM-MEMBERS-SHOWCASE` folder in VS Code.
3. Open `index.html` directly in a browser, or use the Live Server extension.

No installation, dependencies, or build tools are required.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome CDN
- Random User image API

## Notes

- The page is created for presentation and layout practice.
- Social media links and the open positions button currently use placeholder `#` links.
- Profile images and Font Awesome icons are loaded from external services.
- Hover effects are visual CSS effects only; the project has no JavaScript functionality.
