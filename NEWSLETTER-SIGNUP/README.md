# Newsletter Signup

A clean and modern newsletter signup landing page built with HTML and CSS. This project features a dark-themed subscription form, email input, call-to-action button, and benefits list.

## Preview

This page is designed to look polished and professional for a blog, startup, or coding brand.

## Features

- Dark mode UI
- Email signup form
- Responsive layout for smaller screens
- Modern typography and icons
- Clean promotional design for newsletter subscriptions

## Project Structure

- `index.html` – page structure and form markup
- `style.css` – styling, layout, colors, and responsiveness

## How to Run

1. Open `index.html` in your browser.
2. Or use a local development server such as Live Server in VS Code.

## Technologies Used

- HTML5
- CSS3
- Font Awesome icons

## Customization

You can easily modify:

- Brand text and headline
- Button label
- Email placeholder
- Colors and background theme
- Benefits section content

## Example

The form includes:

- Email input field
- Subscribe button
- Benefits such as weekly coding tips and no-spam policy
