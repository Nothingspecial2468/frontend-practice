# Contact Form — Responsive Demo

A simple, non-interactive contact form built to demonstrate responsive layout and styling.

Summary
- Focus: responsive CSS and modern UI (desktop + mobile).
- Behavior: intentionally non-interactive for this project — no validation UI or error messages.
- Icons: Font Awesome is used for input icons.

How to view
- Open `index.html` in a browser (no server required).

Files
- `index.html` — form markup (uses class selectors only).
- `style.css` — responsive styles and UI design.

Notes
- To add client-side behavior later, implement JS that targets the `.contact-form` and input classes.
- The layout uses CSS Grid for responsive fields and is optimized for mobile and desktop.
