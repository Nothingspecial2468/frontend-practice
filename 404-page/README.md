# 404 Page

A simple and stylish 404 error page built with HTML and CSS. It uses a dark theme, bold typography, and a friendly message to guide users back to the homepage.

## 🚀 Features

- Minimal and modern design
- Responsive layout for smaller screens
- Friendly 404 message
- Call-to-action button to return home
- Pure HTML and CSS implementation

## 🛠 Tech Stack

- HTML
- CSS

## 🧠 What I practiced

- Layout design and spacing
- Responsive styling
- Typography and color contrast
- Button and hover interactions
- Creating a polished error-state page

## ▶️ How to run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Or run it with a local preview extension such as Live Server.

## Project structure

- `index.html` – page structure
- `style.css` – styling and responsiveness
- `404.png` – illustration asset
